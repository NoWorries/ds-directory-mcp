Design exploration — homepage visual direction

Three ways to not look like State of AI

The current styling leans on the same monospace-label / blue-accent / card-grid language as State of AI in Design Systems — close enough to read as borrowed rather than considered. Below are three alternate directions, each grounded in something from the actual subject (spec annotation, library cataloguing, the agent/CLI side of the product) instead of a generic "clean SaaS" default.

All three mockups share identical HTML and CSS rules — every color, typeface, and radius comes from one swappable set of custom properties per variant (--surface, --ink, --accent, --font-display…). Picking a direction is then a matter of copying one token block into page_shell.py, not restyling every page.

01 — Blueprint 02 — Card Catalog 03 — Terminal

Blueprint

01 / 03

Drafting-table spec sheets and design-review redlines — crop marks at the corners, a measurement-red accent instead of blue, dashed "unconfirmed" card edges. Reads as a tool for people who annotate specs all day, not a generic dashboard.

--surface #f2f5f4 --ink #12212b --accent #d6482f IBM Plex Mono / Work Sans

Card Catalog

02 / 03

This product's whole job is being an index — so it looks like one. Manila-and-ink card tones, a library-stamp green, a dog-eared corner on every card, small-caps navigation like a drawer label. Warm without falling into cream-paper-plus-terracotta territory.

--surface #f1e8d3 --ink #2b3b2e --accent #4f6b45 Fraunces / Space Mono

Terminal

03 / 03

This is also an MCP server — half its real users are agents in a shell, not people in a browser. Leans into that: full monospace, amber CRT glow instead of the expected neon green, a faint scanline texture, prompt markers ($, >, --flag) standing in for section labels.

--surface #0b1210 --ink #ece7dc --accent #f2b155 JetBrains Mono
